<objective>
Give the canvas an honest level-of-detail control, fan finding badges out to the resources they actually affect,
and make every reduction the workspace performs visible as DOM text.

Purpose: the layout helper only degrades layout quality past its node budget — it never reduces element count, so
at enterprise scale the force simulation still runs over the full set and the tab locks. Badges are keyed on the
control id, which the analyzer populates with the owning NSG or firewall collection, so an operator inspecting the
subnet whose exposure a finding describes sees no badge. The badges toggle gates badges but not the drawer, making
its meaning ambiguous. And the node-id fold index is built once before the peering loop while unresolved peers are
appended inside it, so a later differently-cased reference to the same remote VNet creates a duplicate node for
one real VNet.

This plan owns the workspace and the graph builder. The drawer, the canvas component, and the export are plan
12-10, so no file is shared between them.

Output: a bounded, honestly-labelled canvas whose every reduction is stated in text.
</objective>
