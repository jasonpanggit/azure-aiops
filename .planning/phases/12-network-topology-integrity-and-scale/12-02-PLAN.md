phase depends on. This plan writes no production code.

Purpose: RESEARCH §Wave 0 Gaps and `12-UI-SPEC.md` §Wave-0 test scaffolding both record that the scale/perf test
module, the enterprise-size fixtures, and the shared web fixture helper do not exist. Without them, the TOPO-03

declared cap and ceiling), and G-3 (p95 server build < 1 s at enterprise size) are unassertable, and every later

That is only checkable if the pre-phase bodies are recorded now, while the code still behaves the old way. Once
plan 12-03 lands, the comparison target is gone forever. Task 3 records it.

This plan runs in wave 1 alongside the scope-isolation gate because it touches no file that gate touches and no
production source at all. **Accepted scope deviation:** this plan carries four tasks rather than the usual three.
Every task is test or measurement scaffolding with zero production code, its seven-file scope remains within the
documented target, and its 74,000-token estimate is 26% below the hard budget. Keeping the web fixture task here
also makes every Wave 0 prerequisite available in the same wave; splitting it would add coordination and a
twelfth plan without reducing production-code risk.

Output: reusable estate builders, a baseline-recording scale module, a recorded pre-phase baseline artifact with
a pinned G-4 fixture, an owned empirical canvas ceiling, a shared web fixture helper, and a pinned status-tone
palette test.
