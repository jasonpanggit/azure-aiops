<objective>
Make the drawer answer for every node, including the ones whose facts the lean payload withheld, and make an
exported file carry enough provenance to be trusted later.

Purpose: the drawer returns nothing for node kinds it has no branch for, so an operator clicks a node and gets
silence with no way to tell a bug from an empty result. Once plan 12-07 strips embedded detail from the summary
payload, a drawer that renders those sections as empty would turn a deliberate withholding into an apparent
absence of findings — a strictly worse failure than the payload size it fixed. Exports carry no record of the
limits, filters, or detail level that produced them, and reuse a fixed filename so a second export silently
replaces the first.

This plan owns the drawer and the canvas component. The workspace and graph builder are plan 12-09's, already
merged.

Output: a drawer that always speaks, drill-down that closes the lean-payload gap, and self-describing exports.
</objective>
