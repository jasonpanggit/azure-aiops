<objective>
Build the genuinely greenfield MED-09 concept — a publication manifest tracking active/dormant/retired lifecycle disposition per generated ontology projection — distinct from the existing per-connection ingestion snapshot manifest, which must not be extended or conflated with this one (RESEARCH.md's Pitfall #4).

Purpose: The underlying Fabric item type this repo publishes to (`"type": "Ontology"`) belongs to Fabric IQ, which is explicitly preview with no SLA. A manifest that can mark a physical projection `dormant` (not deleted) and expose a `deployment-blocked` state for anything depending on this preview surface addresses a real, currently-true platform risk, not a defensive abstraction.
Output: `src/ontology/publication_manifest.py` with a queryable lifecycle-disposition registry; a new manifest-record Delta table schema.
</objective>
