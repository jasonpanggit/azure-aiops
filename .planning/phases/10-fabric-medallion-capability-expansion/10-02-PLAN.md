<objective>
Close the one confirmed governance gap in an otherwise-mature integrity stack: `DataQualityValidator` has no ownership/tag-coverage rule, and `OntologyValidator`'s referential-integrity behavior (dangling/self-link/duplicate/confidence-range checks, already implemented and read this session) has no dedicated regression test file confirmed to exist. Implements MED-06's "configurable ownership and tagging quality thresholds" and closes the regression-test gap for its existing referential-integrity half.

Purpose: CONTEXT.md's live baseline cites 84 resources missing ownership and 52 missing tags — without a coded rule, this gap is invisible to every downstream consumer (health API, Data Agent grounding, compliance review).
Output: A new `ownership_coverage`/`tag_coverage` rule in `DataQualityValidator`, per-environment warn/block config, and a dedicated `OntologyValidator` regression test file.
</objective>
