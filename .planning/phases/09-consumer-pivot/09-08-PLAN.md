<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| MCP client → APIM | Bearer token, subscription identity, protocol messages, and possible hostile arguments enter the gateway. |
| APIM → Container App MCP route | Gateway forwards untrusted requests to the governed service and must preserve correlation without granting scope. |
| Terraform/deployment → Azure control plane | IaC and scripts manage gateway resources and must not leak credentials or destroy unrelated infrastructure. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-09-27 | Spoofing | APIM OAuth/JWT policy | critical | mitigate | Validate Entra issuer/tenant/audience, use short-lived bearer tokens, and test invalid audience/missing token. |
| T-09-28 | Elevation of privilege | APIM subscription/product policy | critical | mitigate | Treat subscription keys as consumer controls only; retain API-derived grants and scope checks, with forged-scope tests. |
| T-09-29 | Information disclosure | APIM traces/policies | high | mitigate | Redact authorization, secrets, raw payloads, and sensitive arguments; propagate correlation IDs only. |
| T-09-30 | Denial of service | APIM MCP gateway | high | mitigate | Configure rate/quota/request-size/time limits and verify 429 behavior without changing four-state provider semantics. |
| T-09-31 | Tampering | Terraform state/deployment | high | mitigate | Pin/provider-validate management API, preserve state backups/plan artifacts without secrets, and exercise rollback/re-plan. |
| T-09-SC | Tampering | npm/pip/cargo installs | high | accept | No package installation is planned. |
</threat_model>
