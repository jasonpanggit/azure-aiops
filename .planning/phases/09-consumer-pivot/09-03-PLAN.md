<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Page DOM/state → browser snapshot builder | Client-generated context must be bounded and must reflect rendered state. |
| Browser → Copilot API | Snapshot and question are untrusted and must be validated server-side. |
| API response → operator UI | Evidence, statuses, and model availability must not be visually misrepresented. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-09-10 | Tampering | Frontend PageSnapshot | medium | mitigate | Typed mirrors, named evidence sections, payload bounds, and backend revalidation; never trust client scope. |
| T-09-11 | Information disclosure | Drawer rendering | high | mitigate | Render only API-authorized envelope data and retain evidence/scope filtering on the server. |
| T-09-12 | Spoofing | Foundry/deterministic status badge | medium | mitigate | Render explicit synthesis mode and named agent metadata; deterministic results cannot carry an AI success label. |
| T-09-13 | Denial of service | Retry interaction | low | mitigate | Disable duplicate submissions while loading and preserve server budgets; retry the same bounded snapshot. |
| T-09-SC | Tampering | npm/pip/cargo installs | high | accept | No package installation is planned; existing web dependencies only. |
</threat_model>
