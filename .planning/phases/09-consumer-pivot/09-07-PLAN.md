<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| MCP client → FastAPI MCP adapter | Untrusted protocol messages, arguments, subject identifiers, and headers enter the service. |
| MCP adapter → governed registry/providers | Tool execution crosses into scoped inventory, semantic, and optional Fabric IQ providers. |
| MCP response/ledger → external consumer | Evidence and operational statuses leave the service and must remain attributable and redacted. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-09-23 | Elevation of privilege | MCP scope binding | high | mitigate | Derive effective scope server-side, ignore client scope claims, validate every subject, and test cross-scope calls. |
| T-09-24 | Information disclosure | MCP result/log serialization | high | mitigate | Bound and redact payloads, preserve evidence metadata, and prohibit raw storage/provider access. |
| T-09-25 | Denial of service | MCP dispatch | high | mitigate | Enforce message, argument, response, call-count, concurrency, and wall-clock budgets with cancellation. |
| T-09-26 | Tampering | Tool catalog | high | mitigate | Exact reviewed allowlist, strict schemas, registry-only dispatch, and read-only negative tests. |
| T-09-SC | Tampering | npm/pip/cargo installs | high | accept | No package installation; use existing HTTP/FastAPI stack. |
</threat_model>
