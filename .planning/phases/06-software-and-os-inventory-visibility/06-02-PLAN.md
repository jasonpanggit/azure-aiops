<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| API identity -> workspace query | An Entra-authenticated backend credential accesses only configured Log Analytics workspaces. |
| ConfigurationData -> normalized software | Workspace rows may be stale, malformed, duplicated, or only partially identifiable. |
| scoped API -> browser | Group counts, detail rows, and source warnings cross the delivery boundary. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-06-05 | Information disclosure | workspace mapping and software provider | high | mitigate | Resolve workspace IDs from server configuration, apply effective ReadScope before aggregation, and never accept arbitrary workspace IDs from query parameters. |
| T-06-06 | Tampering | Logs KQL and exact software filters | high | mitigate | Use fixed KQL for ConfigurationData, validate name/version lengths, escape any server-composed predicates, and bound response rows/bytes. |
| T-06-07 | Spoofing | machine/software identity join | high | mitigate | Accept only exact case-insensitive `_ResourceId` matches; preserve unmatched rows as unlinked rather than guessing from Computer. |
| T-06-08 | Information disclosure/availability | failed Logs source | medium | mitigate | Surface source-specific status, timestamps, and warnings; never serialize a failed source as an empty successful inventory. |
</threat_model>
