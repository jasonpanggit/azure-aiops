## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| scoped API envelope -> browser | Authorized rows, facts, review states, and evidence become page state. |
| browser filters/export -> API | User-selected filters and group keys cross server validation. |
| page -> spreadsheet consumer | CSV cells may be interpreted by spreadsheet software. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06-34 | Information disclosure | page filters/detail/export | high | mitigate | Treat API scope as authoritative and export only exact scoped detail responses. |
| T-06-35 | Tampering | CSV serializer | medium | mitigate | Quote cells and neutralize formula-leading values with dedicated utility tests. |
| T-06-36 | Spoofing/information disclosure | provider status UI | medium | mitigate | Render partial/stale/unavailable warnings rather than substituting zero success. |
| T-06-37 | Information disclosure | chart aggregation | medium | mitigate | Derive cards/charts from the same scope-filtered data used by tables and test isolation. |
</threat_model>
