<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| scoped API envelope -> browser state | Authorized summaries/details/evidence become interactive page state. |
| browser filter/export action -> API | User-selected filters and detail keys cross into server validation. |
| page -> spreadsheet consumer | CSV text may be interpreted by spreadsheet software. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-06-17 | Information disclosure | client filters, detail, and CSV | high | mitigate | Treat API scope as authoritative, fetch exact detail by validated group key, and export only the returned scoped rows. |
| T-06-18 | Tampering | CSV serializer | medium | mitigate | Quote all cells and neutralize spreadsheet formula-leading values; cover delimiters, quotes, and line breaks with tests. |
| T-06-19 | Spoofing/information disclosure | provider status rendering | medium | mitigate | Render source warnings and unavailable/partial states with StatePanel/EvidenceBar instead of substituting empty success. |
| T-06-20 | Information disclosure | chart aggregation | medium | mitigate | Derive chart/card counts from the same scope-filtered response used by the table and verify subscription isolation. |
</threat_model>
