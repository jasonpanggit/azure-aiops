<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| raw software identity -> AI suggestion | External strings and model output enter advisory mapping state. |
| reviewer browser -> mapping mutation | Approval/rejection crosses an authenticated write boundary. |
| mapping repository -> grouped inventory | Mapping status determines whether identity can affect aggregates. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06-26 | Information disclosure | mapping list/detail | high | mitigate | Apply effective ReadScope to mapping scope predicates before serialization and aggregation. |
| T-06-27 | Tampering | approve/reject routes | high | mitigate | Require authenticated permission, strict DTOs, expected revision, status transition validation, and atomic mutation. |
| T-06-28 | Tampering | AI normalization | high | mitigate | Validate model output, preserve raw identity, keep suggestions non-authoritative, and require explicit approval. |
| T-06-29 | Repudiation | mapping decision | high | mitigate | Append immutable audit event with actor, action, timestamp, scope snapshot, revision, and provenance. |
</threat_model>
