| Boundary | Description |
|----------|-------------|
| connection credential -> Logs workspace | Backend identity accesses configured workspaces. |
| Logs refresh -> generation | External rows and failures enter durable publication. |
| runtime provider -> API | Source status and exact rows become scoped responses. |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-06-15 | Spoofing/availability | source status | medium | mitigate | Preserve source-specific statuses, timestamps, warnings, and successful-empty distinction. |

</threat_model>
