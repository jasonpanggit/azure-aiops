<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| scoped inventory aggregates -> Foundry | Bounded facts and citations are sent to an optional narration dependency. |
| raw software identities -> normalization suggestion | Messy external strings may be submitted for advisory canonicalization. |
| model output -> grouped inventory | AI output must not become an unreviewed identity or lifecycle mutation. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-06-13 | Information disclosure | narrative context builder | high | mitigate | Apply scope projection before model invocation, include aggregates rather than machine rows, and test subscription/business-service isolation. |
| T-06-14 | Tampering | AI software mapping | high | mitigate | Treat model output as a suggestion, validate schema/confidence, persist mapping provenance, and require explicit approval before grouping changes. |
| T-06-15 | Spoofing | unsupported narrative | medium | mitigate | Keep deterministic facts/citations visible, label narration separately, and return fact-only output on absent or failed Foundry. |
| T-06-16 | Availability | Foundry/normalization provider | low | accept | The core inventory remains usable through deterministic grouping and fact-only narrative with explicit warnings and bounded retries inherited from the existing client. |
</threat_model>
