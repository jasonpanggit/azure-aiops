<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| ARG-shaped fixture/generation -> inventory service | Source-shaped machine records cross normalization and grouping. |
| inventory service -> API | Stored observations become scoped DTOs and evidence. |
| API -> browser | Authenticated operators receive only effective-scope rows. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06-01 | Information disclosure | OS grouping/detail service | high | mitigate | Apply ReadScope before grouping, counts, pagination, evidence, and every detail lookup; assert subscription isolation. |
| T-06-02 | Tampering | group-key and filter validation | medium | mitigate | Use strict typed filters and server-validated group keys; do not accept client-supplied machine lists or KQL. |
| T-06-03 | Spoofing/information disclosure | source failure projection | medium | mitigate | Preserve per-family failure/status rows and distinguish unavailable or partial from successful zero rows. |
| T-06-04 | Information disclosure | native OS lifecycle classification | medium | mitigate | Keep image metadata separate from installed release fields and mark unsupported/unknown versions for review. |
</threat_model>
