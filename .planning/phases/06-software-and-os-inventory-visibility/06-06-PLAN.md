<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| public/vendor/AI source -> adapter | Untrusted external content enters candidate extraction. |
| adapter -> review API | Citation-bearing candidates and failures cross into operator-visible state. |
| confirmation -> catalog document | Only validated operator mutation changes authoritative lifecycle data. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06-21 | Server-side request forgery | official-vendor adapter | high | mitigate | Enforce configured HTTPS host allowlist, redirect limit, timeout, response-size, extraction-size, and no browser URL input. |
| T-06-22 | Tampering | candidate citations/content | high | mitigate | Validate source kind, HTTPS citation, authoritative domains, claim bounds, and preserve source-specific failures. |
| T-06-23 | Information disclosure | web/LLM request | high | mitigate | Send only normalized OS lookup data; never send inventory rows, tokens, or scope details. |
| T-06-24 | Tampering | catalog persistence | high | mitigate | Use validated lifecycle rows, atomic document replacement, revision checks, and operator confirmation only. |
| T-06-25 | Tampering | npm/pip/cargo installs | high | mitigate | No new package is required; if an adapter implementation proposes a package, stop for the package-legitimacy gate before installation. |
</threat_model>
