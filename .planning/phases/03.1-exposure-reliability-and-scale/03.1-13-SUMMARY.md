## Decisions Made

- Authorization resolution remains server-owned. The query service accepts an `ExposureAuthorization` only from its configured resolver and verifies that it belongs to the authenticated principal and effective API scope.
- The list path deduplicates `exposure_id` with a deterministic fact tie-break before keyset ordering, while counts and facets use `COUNT_BIG(DISTINCT exposure_id)` to avoid source-family multiplication.
- Cursor payloads are canonical JSON signed with HMAC-SHA256. Cursor TTL is 15 minutes; the previous managed key is accepted for at most the configured 30-minute overlap and never used for new signatures.
- The local benchmark identifies itself as `deterministic_fabric_sql_contract` and never claims production certification. The same harness has a `--require-ready` mode that selects the real Fabric SQL reader, requires explicit tenant/connection/subscription/generation inputs, and exits nonzero on readiness or budget failure.
