## Decisions Made

- `first_observed_at` remains only as a compatibility alias for exact `first_detected_at`; publication, ingestion, run, enrichment, and episode times cannot populate it.
- An enabled temporal reader treats projected current state—including an explicitly empty result—as authoritative. Legacy rows supply compatibility detail but cannot decide active state.
- Runtime KB rows retain the durable projected `current_key` and derive compatibility finding identities as `current_key|CVE`, preserving deterministic multi-CVE expansion.
- The typed `fabric.exposure.enabled`/`rollback_mode` configuration selects temporal versus legacy behavior; no browser or request parameter can select the authoritative reader.
