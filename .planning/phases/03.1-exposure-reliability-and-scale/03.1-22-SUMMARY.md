## Decisions Made

- Exact canonical internal paths, rather than free-form labels or URL prefixes, are the only accepted detail origins. This makes the query value presentation context rather than navigation authority.
- Each section requests its own common Exposure overview contract alongside its own source payload. This deliberately avoids a shared promise whose failure would make all six sections fail together.
- The common contract owns trust state and connection coverage. Source envelopes own loaded and total item counts. The UI labels both units explicitly instead of merging them.
- The Overview no longer renders either patch inventory or a raw authoritative finding list. Operational row exploration remains on dedicated pages.
