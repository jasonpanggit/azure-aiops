## Decisions Made

- pyodbc remains optional for local/test installations but is mandatory and pinned in the production image.
- The production adapter check is exhaustive and reports only stable reason codes and safe booleans/counts; credential values and provider error text are never included.
- An enabled non-rollback production profile must use Fabric SQL. Delta can be selected only by disabling production Exposure serving or deliberately setting rollback mode.
- Cursor secrets remain versioned in Key Vault and are consumed through versionless Container Apps references using the existing user-assigned identity. Only non-secret kids and secret version identifiers appear in operational output.
