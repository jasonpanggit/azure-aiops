## Decisions Made

- The common contract is nested additively under existing response shapes during migration. This preserves current web and legacy consumers while providing one exact semantic comparison surface.
- The public external catalog remains separate from the scoped Exposure query and explicitly declares that it contains no environment-membership information.
- Missing principal context never falls through to the SQL service. MCP and API Copilot pass the authenticated principal; the root plugin refuses requests without API-derived principal and scope.
- Container application/service context is released only when an exact observed digest, complete evidence, and non-stale freshness all agree. Unknown or degraded evidence cannot claim a safe blast radius.
- Review handoffs are write-authorized but non-executable. They require explicit risk acknowledgement or a matching active exception and do not create, mutate, approve, or execute a remediation plan.
- Existing approval and execution routes were not moved or duplicated. Their established authorization, lineage, accounting, and diagnostics semantics remain the authority.
