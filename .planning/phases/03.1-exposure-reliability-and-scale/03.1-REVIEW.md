# Phase 03.1 Publication Optimization: Code Review Report

**Reviewed:** 2026-09-13
**Depth:** Deep cross-file review of publication checkpoint persistence, automatic
resume, Delta write fencing, ambiguous commit reconciliation, rollback truth,
OneLake artifact streaming, operator monitoring, and temporal projection cost.
**Status:** Clean after all findings and recommendations were fixed and re-verified.

## Scope and Phase Boundary

The review covered commits `a5ea6e59b`, `df867668a`, and `1b6f75236`, which
restore interrupted publication and optimize temporal projection. The active
project phase is Phase 4, Domain Coverage and Operational Twin. This review does
not close Phase 4's retained evidence gate: the exact supported Defender
digest-to-Container Insights workload round trip, qualified 100k benchmark, and
live canary/rollback exercise remain outstanding.

## Findings and Resolution

| ID | Severity | Finding | Resolution |
|----|----------|---------|------------|
| F1 | Warning | Automatic normal restarts ignored resumable checkpoints and `persist()` could erase them. | Normal runs now resume matching non-finalized checkpoints; explicit replay alone returns finalized outcomes. Finalized checkpoints can be safely superseded, while non-finalized manifest mismatches fail without deletion. |
| F2 | Warning | The progress monitor searched for `elapsed_seconds` as the first JSON key and missed sorted structured events. | Whole-message and embedded-object parsing now identify `event=activation_progress` independent of key order. |
| F3 | Warning | Remote artifact reads used Unicode-aware `splitlines()`, fragmenting JSON rows containing U+2028, U+2029, or U+0085. | Remote streaming now splits only on the JSONL newline delimiter. |
| F4 | Warning | Artifact iteration held process and interprocess locks across generator yields, enabling recovery-path deadlocks. | A consistent disk-backed snapshot is acquired under lock, locks are released before yielding, and checkpoint readers close iterators deterministically. |
| F5 | Warning | APPEND duplicate-row skips bypassed the publication version fence. | The observed preflight version is fenced before any skip result. |
| F6 | Warning | Partial rollback retained completed-table records for successfully reverted tables. | Successful rollback results are cleared before abandonment decisions; incomplete rollback diagnostics provide explicit resume-or-abandon guidance. |
| F7a | Warning | Malformed job/execution JSON could leave the monitor looping with blank status fields. | Required extraction is checked and exits nonzero with a diagnostic. |
| F7b | Warning | INT/TERM cleanup traps removed state without terminating the monitor. | EXIT cleanup and signal-specific terminating traps are separate. |
| F7c | Warning | Log Analytics failures silently hid checkpoint and table panels. | Query failures emit concise, deduplicated non-fatal availability notices. |
| S1 | Info | Checkpoint persistence cost was not attributable in the Phase 4 scale gate. | Existing serialization now accumulates and emits persisted row and UTF-8 byte counts, including JSONL newline bytes. |
| S2 | Info | A saturated 128-entry Delta history scan was reported like a definite missing transaction. | Saturation raises a distinct actionable history-truncation error that reconciliation preserves. |
| S3 | Info | Table-plan mismatches omitted the differing table names. | Errors now include deterministic, bounded added/removed table names and counts without row data. |

The temporal `current_key` timestamp index was reviewed and retained unchanged:
it preserves the previous maximum-`ingested_at` semantics while replacing a
repeated scan with a linear index.
