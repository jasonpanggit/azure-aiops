## Decisions Made

- Partition identity excludes query result content and timestamps so retries address the same connection/family/scope checkpoint; query rows are validated children of that partition.
- Family activation is all-or-nothing across the queries contributing to one semantic family. A partial family attempt cannot mix new rows with prior rows and present the result as current.
- Healthy-empty is usable and advances the effective generation; provider failure is never interpreted as empty.
- Live failures expose only a stable safe error code/summary and a configured display name. Provider exception text, credentials, and arbitrary connection payloads remain private.
- Freshness family normalization maps detailed provider names into exactly five policies. Defender image evidence uses the image policy, while Container Insights families use the workload policy.
