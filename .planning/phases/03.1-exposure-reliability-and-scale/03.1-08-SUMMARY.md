## Decisions Made

- Accepted the one-way temporal contract exactly as delegated: observation/current identity and precedence are now versioned durable data contracts.
- Provider event time is the only source of `first_detected_at`; when any historical missing/reintroduced observation lacks trusted provider time, the first-ever detection remains null and explicitly `unknown`.
- Successful `installed` or `resolved` evidence closes only the matching normalized evidence family. Other active families continue to hold the aggregate Exposure key open.
- Historical observations are never deleted during rollback. Operators restore the prior reader/current-generation pointer or current-table Delta version while retaining v1 history for replay and migration.
- Temporal publication uses a dedicated writer in the declared vulnerability pipeline rather than editing the shared sync dispatcher, honoring the no-overlap constraint while preserving all existing Fabric products.
