## Decisions Made

- URL state remains presentation context, never authorization. Detail parsing starts from the current authorized scope, accepts only two exact internal parent paths, and cannot create an external return target.
- Canonical Exposure item pages own affected-finding totals and cursor pagination. Existing CVE/KB endpoints remain in place for detail metadata, so no `[cveId]`, `[kbId]`, alias, or replacement API route was introduced.
- Missing durable source status is unavailable, even if a compatibility payload contains numeric defaults. A proven EPSS value of zero is distinct from an unproven zero.
- The route maps the existing immutable risk-exception identifier to the dialog audit result, matching the established remediation-page adapter; the server continues to own subject attribution, evidence binding, transition eligibility, and revocation.
