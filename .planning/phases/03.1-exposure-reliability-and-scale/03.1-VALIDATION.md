## Sampling Rate

- **After every task:** Run the narrowest backend/frontend tests covering the
  changed contract.
- **After every plan wave:** Run all Exposure, Fabric, ontology, API, and web
  focused tests.
- **Before `/gsd-verify-work`:** Full backend suite, frontend lint/tests/build,
  100k deployed-adapter benchmark, shadow reconciliation, and authenticated
  UI validation must be green.
- **Maximum feedback latency:** 120 seconds for task-level automated checks.

## Performance and Reconciliation Gate

- Generate 100,000 deterministic Gold findings across multiple scopes, source
  classes, severities, target kinds, and tied scores.
- Run five warmups and at least twenty measured queries against the deployed
  adapter.
- Record p50, p95, and p99 for default first page, scoped filtered page,
  next-page keyset query, and summary.
- Require filtered first-page server p95 at or below two seconds.
- Walk every page and assert exact total, unique stable IDs, deterministic
  order, bounded response size, and no request-time provider calls.
- Reconcile Silver, Gold, ontology, API, remediation, web, and Copilot
  identities/counts for the same generation and scope.
