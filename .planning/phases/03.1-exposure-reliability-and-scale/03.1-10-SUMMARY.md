## Decisions Made

- The granular v1 identity contract is now durable. Any later key composition change must use an additive contract version, backfill retained rows, support old and new readers during migration, regenerate ontology relationships, and roll back by generation pointer/table version rather than reinterpret stored v1 evidence.
- Registry and repository define a logical image. Canonical sha256 defines a digest. Tags are mutable aliases only.
- Defender source event plus digest, CVE, and provider event time define an immutable vulnerability observation. A Fabric retry/run ID is lineage, not provider identity.
- Existing exact workload deployment rows remain the only deployment authority. Registry, repository, tag, ARG membership, and name similarity cannot create a deployment or server identity.
- Container priority includes workload impact only when an exact deployment exists; unknown coverage remains in totals and reason counts.
- Container findings cannot enter server patch eligibility. Phase 11-owned Copilot/Foundry paths were not modified.
