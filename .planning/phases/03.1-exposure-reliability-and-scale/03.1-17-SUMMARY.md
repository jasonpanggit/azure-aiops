## Decisions Made

- The common Exposure read model is authoritative for patch priority/inventory rows; legacy aggregate endpoints are not mixed into the new table.
- URL state is context, never authorization. The remediation return path is allowlisted to internal `/exposure` routes and re-canonicalized against effective authorized scope.
- Server execution remains the existing approval-bound workflow and is revalidated immediately before `execute`; no action type or adapter was added.
- Container review accepts only explicit `review_handoff` cases with `direct_execution_supported: false`, and the POST result must also confirm no execution transition.
- Risk revocation uses stop-on-first-failure scheduling because continuing after an unknown audited failure would make the batch result misleading.
