## Decisions Made

- Adopted the accepted additive versioned checkpoint/deployment contract. The checkpoint key is derived from version + connection + workspace + source family; tags and repositories are excluded from deployment identity.
- Kept Defender `imageDigest` as the digest-level vulnerability authority. Container Insights can prove deployment only when its immutable `sha256` matches exactly and all required observations fall inside the 15-minute window.
- Retained old exact deployments only when that deployment already exists in LKG. A stale component partition is not sufficient to create a deployment for a newly observed Defender finding.
- Kept historical compatibility additive: Fabric reads `exposure/workload_*` first and accepts legacy `workload/workload_*` paths during migration; rollback leaves retained source generations and prior Fabric table versions intact.
