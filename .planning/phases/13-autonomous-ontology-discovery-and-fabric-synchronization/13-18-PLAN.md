## Trust Boundaries

| Boundary | Description |
|---|---|
| Browser/caller → API | Scope, IDs, ETags, reasons, and idempotency values are untrusted. |
| API → isolated command-intake store | A non-writer queues manual-run or rollback intent without access to authoritative state. |
| OneLake state → API/UI | Durable records may be stale, corrupt, or cross-scope. |

| T13-G18-02 | Information Disclosure | lifecycle reads | critical | mitigate | Effective scope before lookup, exact token matching, bounded allowlisted projections, 404 non-disclosure. |
| T13-G18-03 | Tampering | ETag/idempotency | high | mitigate | Current-pointer ETag validation and deterministic command identity/CAS. |
