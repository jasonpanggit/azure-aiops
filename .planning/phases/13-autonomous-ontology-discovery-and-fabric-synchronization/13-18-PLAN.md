| Boundary | Description |
|---|---|
| Browser/caller → API | Scope, IDs, ETags, reasons, and idempotency values are untrusted. |

| OneLake state → API/UI | Durable records may be stale, corrupt, or cross-scope. |
| Maintenance caller → coordinator cadence | A privileged non-production-only command crosses API intake but cannot mutate cadence until coordinator reauthorization. |
