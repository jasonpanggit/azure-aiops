## Trust Boundaries

| Boundary | Description |
|---|---|
| Connection registry/Azure evidence → coordinator | Durable but untrusted connection metadata selects provider work. |
| Foundry request/response → policy/candidate | The bearer-authenticated external call carries scoped evidence; model output remains advisory data and cannot supply authority or scope. |
| Replica → OneLake lifecycle documents | Independent workers contend on shared run and dispatch state. |
| Command intake → coordinator authority | Immutable caller intent is untrusted until the coordinator re-resolves scope, action, connection eligibility, and expiry. |
| Coordinator → dispatch workspace | Only validated deterministic candidates cross into authoritative publisher work; API has no route or root to this workspace. |
