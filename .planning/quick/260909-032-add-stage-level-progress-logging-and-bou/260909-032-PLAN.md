<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Azure/service failures → activation progress | Provider exceptions may contain credentials, tenant/subscription/resource identifiers, URIs, or response payloads that must not cross into operator logs |
| Concurrent Fabric workers → progress callback | Multiple table-write completions race to update shared counts and the active stage |
| Heartbeat worker → process lifecycle | A background thread must stop on success and every exception path and must not amplify log volume |
| Fabric staging → Gold pointer | Observability executes around an authority-changing pointer CAS whose ordering must remain unchanged |
| CLI progress stderr → terminal stdout consumer | Human-readable progress must not corrupt scripts that parse the final stdout document |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-Q032-01 | Information disclosure | terminal failure, callback logging, and progress serialization | high | mitigate | Enforce exact stage/status key sets and bounded count values; callback failures log fixed message/error-code pairs without dynamic arguments or `exc_info`; use caplog and rendered-stream regressions with planted secrets/resource IDs. |
| T-Q032-02 | Denial of service | heartbeat worker | medium | mitigate | Use one daemon worker, positive configurable interval, stop event, bounded one-per-interval emission, callback isolation, and deterministic shutdown tests. |
| T-Q032-03 | Tampering | concurrent progress counts | medium | mitigate | Keep `FabricSyncService` as count authority, emit only after successful `DeltaWriteResult` recording, and protect reporter stage state with a lock. |
| T-Q032-04 | Elevation of privilege | Gold pointer activation | high | mitigate | Add no cloud calls or authority changes; use a real-hook trace for the entire publication sequence and parameterized failure injection at every pre-activation hook to prove the pointer remains untouched. |
| T-Q032-05 | Repudiation | activation stage timeline | low | mitigate | Stable event/stage/status names plus monotonic elapsed seconds establish an ordered local process timeline without sensitive identifiers. |
| T-Q032-06 | Tampering | CLI output channels | medium | mitigate | Write flushed progress JSON Lines only to stderr and preserve one terminal JSON document on stdout; test both channels independently. |
| T-Q032-SC | Tampering | package-manager installs | low | accept | No dependency or package-manager change is planned. |
</threat_model>
